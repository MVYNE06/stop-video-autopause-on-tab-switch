Stop Videos from Auto-Pausing When Switching Tabs or Windows

Always-Active Media is a lightweight, open-source browser extension for Chrome, Brave, Edge, and Firefox that stops online learning platforms (Udemy, Coursera, Canvas, edX, Panopto, Kaltura) and media players from automatically pausing playback when you switch tabs, minimize the browser, or take notes on a second screen.

How It Fixes Auto-Pause (Without Breaking the Web)

Websites pause background videos by checking document.hidden, document.visibilityState, and listening to visibilitychange or window.onblur. Unlike older extensions that inject onto every website and break Slack/Discord desktop notifications, Always-Active Media uses a per-domain toolbar toggle.

  • One-Click Activation: Click the extension icon on any site to toggle the green ON badge.
  • Cross-Origin Iframe Support: Works automatically inside embedded Vimeo, Kaltura, and Panopto lecture players.
  • Non-Intrusive Event Guarding: Blocks window-level focus loss while leaving HTML inputs, dropdown menus, and search bars 100% functional.

Quick Installation Guide

  1. Download and extract the latest ZIP from the GitHub Releases page.
  2. In Chrome, Brave, or Edge, open chrome://extensions and enable Developer mode (top right).
  3. Click Load unpacked and select the extracted folder.
  4. Open your lecture tab, click the extension icon in your toolbar so it says ON, and multitask freely!
